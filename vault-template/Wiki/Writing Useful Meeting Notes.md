# Writing Useful Meeting Notes

> [!note] Example note
> Fictional sample content that shows how the dashboards fill in. Delete it once you have your own.

> [!abstract] At a glance
> Capture decisions and owners, not a transcript. Use this when you start a [[Templates/Meeting Template|meeting note]].

**Related:** [[Wiki/Wiki Hub|Wiki Hub]]

## Notes

- Put a two-line TL;DR first, so the note is useful at a glance.
- Record decisions separately from discussion.
- Give each action item an owner and a date, as a Tasks-plugin checkbox.
- Track only what others owe you in the "Waiting on others" table, and set `status: ⌛ Waiting on others` while it is open.
